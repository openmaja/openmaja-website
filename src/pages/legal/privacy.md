# Privacy Policy

*Last updated: May 2026*

## This website

openmaja.org is a static website hosted on GitHub Pages. It does not collect, store, or process any personal data.

There are no analytics trackers, cookies, or forms on this site.

## GitHub Pages

This site is hosted by GitHub Pages. GitHub may collect standard web server logs (IP addresses, request timestamps, user agents) as part of their infrastructure. See [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for details.

## OpenMaja software

When you deploy OpenMaja sub-projects (such as FolderBot) in your own environment, data processing is governed by your organization's policies and the third-party services you use (Microsoft 365, Azure, etc.). OpenMaja software does not transmit data to any OpenMaja-controlled servers.

## Contact

For privacy-related questions, open an issue on the [OpenMaja GitHub organization](https://github.com/openmaja).
